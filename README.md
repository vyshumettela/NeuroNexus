# NeuroNexus Task 1 - Landing Page

## 👨‍💻 Task Description
This project is a part of the NeuroNexus Innovations internship. The objective was to create a Google Form-like landing page using **only HTML and CSS**.

## 🌐 Features
- Collects the following details:
  - Full Name
  - Contact Number
  - Address
  - Company Name
  - Email Address
  - Department (Dropdown)
  - Gender (Radio Buttons)
- Responsive and clean layout

## ✅ Bonus Features Implemented
- Hover effect on the submit button
- Background color of the form different from the page
- Minimalistic box-shadow for better UI

## 📁 Files Included
- `index.html` – Main HTML structure
- `style.css` – Styling for the form
- `task1_demo.mp4` – Demo video showcasing the working form

## 💡 How to Use
1. Open `index.html` in any web browser to view the form.
2. Customize or improve styles in `style.css`.
